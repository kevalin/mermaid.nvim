A plugin for Neovim · Mermaid diagrams

Write Mermaid diagrams in Neovim. See them instantly.

mermaid.nvim gives your .mmd buffers a live browser preview, a built-in formatter, lint diagnostics, and inline rendering for Kitty/Ghostty terminals — with zero dependencies for the core features.

Everything a diagram workflow needs

mermaid.nvim bundles the full loop — highlight, format, lint, preview, render — in plain Lua. Optional integrations are clearly marked.

Live preview no deps

Real-time browser preview powered by a built-in Lua HTTP server with Server-Sent Events. Updates as you type.

Dual renderers no deps

Choose the standard mermaid.js renderer or the aesthetic beautiful-mermaid — one config option.

Inline render mmdc + chafa

Render diagrams directly inside Kitty and Ghostty via the graphics protocol, or fall back to chafa ASCII/ANSI.

Auto-format no deps

Built-in formatter normalizes indentation and token spacing across Mermaid diagram types.

Diagnostics mmdc

Lint errors surface as vim.diagnostic signs via mermaid-cli, auto-detected when installed.

Floating panel no deps

An in-editor panel shows the preview URL, connection status, and quick actions.

Dark mode sync no deps

Auto-detects Neovim’s background setting and live-syncs the browser preview theme.

Preview toolbar no deps

Zoom, pan, copy PNG to clipboard, and download SVG — right in the browser preview.

● no external dependencies● optional — feature degrades gracefully without it

Installation

Three steps to a working setup. The core plugin has no dependencies; Tree-sitter provides syntax highlighting.

Add the plugin with your plugin manager

Shown with lazy.nvim; any plugin manager works.

return {
    "kevalin/mermaid.nvim",
    dependencies = { "nvim-treesitter/nvim-treesitter" },
    config = function()
        require("mermaid").setup()
        -- Install the Tree-sitter parser: :TSInstall mermaid
    end,
}

Install the Tree-sitter parser

Syntax highlighting for .mmd / .mermaid files comes from Tree-sitter.

:TSInstall mermaid

Add optional tooling

Diagnostics and inline rendering use mmdc; chafa enables ASCII/ANSI rendering on Neovim 0.9.5–0.11.

# Optional diagnostics
npm install -g @mermaid-js/mermaid-cli

# Optional terminal fallback
# Debian/Ubuntu: sudo apt install chafa

Then open a .mmd file and run :MermaidPreview.

The same flowchart, rendered both ways. Switch with preview.renderer and pick a theme per renderer.

Render inline — or in the browser

The available path depends on your terminal and Neovim version. Run :MermaidRender to try it.

Configuration defaults

require("mermaid").setup({
    format = { shift_width = 4 },
    lint = { enabled = true, command = "mmdc" },
    preview = { renderer = "mermaid.js", theme = "default" },
})

FAQ

Common questions — more answers are in the README troubleshooting section.

The preview opens but shows “Loading…”

Make sure the buffer has content and the SSE connection is established. Check the preview connection indicator.

:MermaidFormat broke my diagram

Add -- mermaid-format-ignore to lines the formatter should skip.

Can I use this without a browser?

Yes. Use :MermaidRender with Kitty/Ghostty on Neovim 0.12+, or install chafa on older versions.

Does this work on Windows?

The plugin is Lua-based and runs anywhere Neovim runs.
